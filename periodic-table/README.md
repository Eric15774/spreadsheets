# Periodic Table Screensaver

An animated periodic table that zooms in on a random element every 20 seconds or so and shows a card with key facts: atomic mass, state, melting and boiling points, density, electronegativity, discovery, electron configuration, uses and where it is found.

Live page: https://eric15774.github.io/spreadsheets/periodic-table/screensaver/

Click or press Space to skip ahead. Press F for full screen.

## Data notes

- Element data comes from Eric Longwell's periodic table data workbook.
- Observed electron configurations for La, Ce, Gd, Pt, Au, Ac, Th, Pa, U, Np, Cm and Lr were corrected to the accepted observed values.
- Discovery years for Rf through Og were added. C, S, Fe, Cu, Ag, Sn, Au, Hg and Pb are shown as known since ancient times.
