# Spreadsheets

A collection of task-specific spreadsheets and data sets, mostly for teaching.

## Contents

| Folder | What it is |
|---|---|
| [physics](physics/) | Physics calculators, worked problems, lab data tables and reference data |
| [nuclides](nuclides/) | IAEA Chart of Nuclides data (2024): half-lives, decay modes and binding energies for 3,358 nuclides, stable and radioactive |
